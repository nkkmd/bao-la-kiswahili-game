# SSGTC-STUDY1 — Results Directory

No scientific result is committed here at study start.

Stage 0 outputs are technical diagnostics only. A Stage 0 result may be materialized into this directory only after the frozen runner executes, independent verification passes, and the repository-facing artifact is re-opened and re-hashed successfully.

Any committed result must state whether it is:

- technical diagnostic only;
- exact within a frozen bounded domain;
- observed/censored only;
- estimated under a separately frozen estimator protocol;
- or non-estimable/technically invalid under the applicable decision framework.

Repository-facing projections are never authoritative raw-state identity sources.
