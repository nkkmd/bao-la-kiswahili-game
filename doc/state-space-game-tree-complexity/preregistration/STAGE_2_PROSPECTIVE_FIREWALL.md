# SSGTC-STUDY1 — Stage 2 Prospective Firewall

Status: **NOT AUTHORIZED / NOT EXECUTED**.

This document freezes the minimum conditions that must be satisfied before any Stage 2 formal evidence is generated. It does not itself authorize Stage 2.

## Authorization prerequisites

Stage 2 requires all of the following:

1. Stage 0 decision is `SSGTC-STAGE0-PASS`.
2. Stage 1 executes only under its pre-frozen resource/stopping checkpoint and has no unresolved representation, replay, materialization, or verifier failure.
3. A versioned Stage 2 formal specification is committed before any Stage 2 outcome generation.
4. Stage 2 uses a fresh root/seed/domain namespace not used as Stage 0 or Stage 1 evidence.
5. Stage 1 rows, counts, and trajectories are not reused as formal Stage 2 evidence.
6. The formal target/domain is selected using a predeclared feasibility rule, not because its exploratory growth/branching/transposition pattern is favorable.
7. Numeric resource caps and stopping/censoring rules are frozen before formal execution.
8. Production and independent verification responsibilities and artifact hashes are frozen before formal execution.

## Preferred formal scope

The first formal Study 1 target should be a defensible **bounded RAW-ONLY domain** rather than a global Bao state-count claim if complete Bao enumeration is infeasible.

Possible formal quantities include bounded reachable raw-state growth, branching summaries, and transposition structure inside a frozen computation domain. Exactness must be stated only at the level actually exhausted and verified.

## Estimator rule

No global or sampled estimator is authorized by this firewall. If estimation is later scientifically justified, a separate preregistration must freeze, before the relevant formal data:

- estimand and target population;
- sampling mechanism;
- estimator;
- censoring/truncation treatment;
- coverage assumptions;
- duplicate handling;
- uncertainty calculation;
- failure/non-estimability conditions.

A censored exact run may not be renamed an estimate.

## Resource failure

If the frozen formal target exceeds resources, the result must preserve that fact using the predeclared decision framework (for example resource-censored/non-estimable as applicable). Resource failure is not permission to change depth, identity, seeds, symmetry, estimator, or endpoint after outcome inspection.

## Symmetry

Study 1 remains RAW-ONLY at Stage 2. Any future symmetry-reduced count requires a separate prospective study/versioned protocol after an independently validated transformation set exists.
