# PBAI-P4 — 工程と依存関係

本書は[事前固定条件](PROTOCOL.md)の工程を案内する文書である。数値条件は同契約を正本とし、ここで新しい条件を付け足さない。

| Stage | 工程 | 後段へ進む条件 |
| --- | --- | --- |
| PBAI-P4-A | 現在main、競合作業、履歴、命名規則の確認 | 新規性と開始認可の成立 |
| PBAI-P4-B | baseline-only診断、比較条件の固定 | baselineとcontractの固定完了 |
| PBAI-P4-C | 隔離実装と正確性、UI・Worker回帰 | 不一致0、指定境界coverage、関連回帰PASS |
| PBAI-P4-D | developmentの同等性・速度・運用・先後対局 | 各数値gateと独立検算PASS |
| PBAI-P4-E | 未使用validationで同じ検証 | 同じ数値gateと独立検算PASS |
| PBAI-P4-F | 最終holdoutと正式判定 | 事前条件への対応を固定し、成功・保留・棄却を区別 |
| PBAI-P4-G | 関連文書の監査とレビュー可能なPR | 証拠・判断・公開状態の整合性と日本語品質PASS |

最終判定が改善を支持しなくても、成立しなかったgate、未実行の理由、seed消費状態を残してProgramを閉じる。未実行を効果なしと読み替えない。

公開配備とAI世代昇格は、この工程に含めない。別途ユーザーの明示的指示が必要である。
