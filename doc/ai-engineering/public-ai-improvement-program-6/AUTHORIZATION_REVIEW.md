# PBAI-P6 — 開始レビュー

## 開始判断

2026年9月8日のユーザー指示「まずは『論理ゲート型評価器がAI-GEN3を実際に強化できるかの検証』を目標として進めます」に基づき、新規の工学検証を開始する。計画だけでなく、実験基盤の実装、学習、事前条件に従う段階的な評価、独立検算までを対象とする。

開始時にGitHubのmainを取得し、`5caa1216a891b5b78f63a81bb559029d482c0181`を確認した。公開系統は`AI-GEN3`、正式リリースは`AI-GEN3-RELEASE-001`。P1〜P5は完了済みであり、未使用のProgram ID `PBAI-P6`を割り当てた。作業は`engineering/pbai-p6-logic-gate-evaluator`で行う。

正式英語題目は `Logic-Gate Evaluator Feasibility and Strength Verification Program 6`。日本語題目は「論理ゲート型評価器によるBao AI強化の実現可能性・棋力検証」である。

## 設計根拠と範囲

AI-GEN3の評価は、盤面上の特徴に加え、合法手生成と捕獲手適用を使っている。学習した安価な評価器でこの処理を置き換え、評価精度と持ち時間内の探索能力の釣り合いを検証する。論理ゲート型が速い、または強いという結果を前提にしない。

P5の固定条件下の速度・棋力改善を既知の設計根拠として参照した。P1〜P5の正式判断、Research Generation 1〜4の研究判断は変更しない。研究用の局面集団・教師ラベル・保護seedは学習へ転用しない。P4/P5の既知識別情報だけを除外に使用し、過去の成績を新規標本へ加算しない。

実装方式の参考資料は[原論文](https://arxiv.org/abs/2210.08277)と[公式実装](https://github.com/Felix-Petersen/difflogic)。画像認識の高速化をBaoでの速度の根拠とはしない。今回の実装はNumPyで独自に記述する小規模な検証用実装であり、公式ライブラリーの再現実験ではない。

## 承認する工程と公開境界

契約と実行ソースを新規結果の生成前にcommitし、ハッシュを照合した後、単一の監視器で開始する。先行段階が条件を満たせば後続へ自動進行できる。必要な条件を満たさなければ停止し、未実行工程を効果なしと解釈しない。

今回の指示はmain統合、公開AIの切替、正式採用、AI世代昇格を含まない。公開ファイルは変更せず、実験用の独立した読み込み環境で評価器を差し替える。サブエージェントは使用しない。
