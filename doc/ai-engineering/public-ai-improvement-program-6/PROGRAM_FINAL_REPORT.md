# PBAI-P6 — 論理ゲート型評価器の検証結果

## 結論

正式判断は **`DEVELOPMENT-GATE-FAIL / HOLD`**。固定した論理ゲート型候補`PBAI-C012-v1`は、開発用128局面で教師の探索値に対する誤差条件と既知の戦術8件を通過したが、速度条件を満たさなかった。このため対局試験へ進まず、Programを開発段階で終了した。

**AI-GEN3を強化できたという結論は得ていない。** 一方、今回の候補の保留は、論理ゲート型の方式全体に強化の可能性がないという意味ではない。棋力対局は0局であり、「対戦で弱かった」と解釈してはいけない。公開判断は`NO-RELEASE / KEEP-AI-GEN3`。

## 何を実装したか

公開の`public/`は変更せず、AI-GEN3の固定ソースを独立したJavaScript環境へ読み込み、評価器を渡す窓口だけを追加した。探索・合法手生成・勝敗判定は基準実装を使った。評価器未指定時、現行評価器を明示した場合とも、人工・既知局面の固定D2探索が基準の選択手と時間以外の全統計に一致した。

主候補は、399個のBoolean入力、3層×512ゲート、学習後に離散化した真理値表、整数化した線形読み出しからなる。ゲート部分は学習されているが、最終評価値の集約には整数係数の加算を使う。全演算がBooleanゲートだけで完結する回路ではない。

比較用に、同じ入力・教師を使う線形ridge評価器`PBAI-C013-v1`と、隠れ32ユニットの小型ニューラルネット`PBAI-C014-v1`を実装した。1方式1設定・1初期値・最終epochだけを採用し、開発用結果を使った選択や追加学習をしていない。

| 学習用 | Namua512、Mtaji512、計1,024 root |
| 学習時の視点 | 両者の視点を同じsplitで扱い、計2,048入力 |

| 最終holdout | 未生成 |
| 対局試験 | 全段階を通じて0局 |

教師は近似探索値であり、真の勝率やゲーム理論的価値ではない。「誤差が小さい」はこの教師に近いことを意味する。

学習用は1,281 seedを開き、1,024 rootを採用した。開発用は155 seedを開き、128 rootを採用した。最大アクセスseedはそれぞれ831001494、832000170であり、その範囲内でもphaseの必要数に達した後は生成を省略したseedがある。正確なアクセス一覧はarchiveの`seed-access.jsonl`にある。

RAW・12手prefix・全source系列の識別情報を用いて、既知のP4/P5識別情報およびsplit間の重複を除外した。標準初期局面や12手未満の共通prefix、未採用局面での合流まで完全に独立とは主張しない。過去の科学研究コーパスは使用していない。

## 開発用評価の結果

小さい値ほど教師への誤差が小さい。時間比は各rootで測った候補／AI-GEN3の比をphase別に中央値で集計している。1未満なら候補が速い。

| 評価器 | 教師への平均二乗誤差 | Namuaの時間比 | Mtajiの時間比 | 全root時間比のp95 | 既知戦術 |
| --- | ---: | ---: | ---: | ---: | ---: |
| AI-GEN3 | 0.127453 | 1.000 | 1.000 | 1.000 | 8/8通過 |
| 論理ゲート型 | 0.074154 | 2.619 | 1.125 | 7.545 | 8/8通過 |
| 線形 | 0.077292 | 0.390 | 0.171 | 1.064 | 8/8通過 |
| 小型ニューラルネット | 0.081889 | 0.436 | 0.214 | 1.171 | 6/8通過 |

論理ゲート型の全体誤差は現行静的評価より約41.8％小さかった。ただしphase別では、Namuaの誤差は現行0.016788に対して候補0.022367と大きく、Mtajiは現行0.238118に対して候補0.125940と小さかった。全体値だけで全局面に改善があるとは扱わない。

主候補の速度は、Namuaで約2.62倍、Mtajiで約1.13倍の時間を要した。事前条件は「両phaseの中央値比0.90以下、全root時間比のp95が1.10以下」であり、いずれも未達だった。

| 主候補の開始条件 | 判定 |
| --- | --- |
| 教師への誤差が現行の1.10倍以下 | PASS |
| 両phaseの評価時間中央値比が0.90以下 | FAIL |
| 全root時間比のp95が1.10以下 | FAIL |
| 既知戦術8件通過 | PASS |
| 基準AIの既知戦術8件通過 | PASS |
| 学習後の出力変換・照合 | PASS |

参照用の線形評価器は、小さい誤差と短い評価時間を両立した。これは後続検討の材料だが、今回の主候補を線形へ取り替えたり、線形の棋力改善・正式採用を宣言したりしていない。小型ニューラルネットには既知戦術2件の失敗もあった。

## 費用構造の診断

開発用各phaseの先頭16 rootで計測器を挿入した診断では、捕獲手の適用が評価全体に占める時間比の中央値はNamua約68.3％、Mtaji約71.0％だった。適用呼出数の中央値は7回と5.5回。これは計測器を含む参考値であり、厳密な費用分解や端末一般の比率ではない。

今回の結果では、こうした処理を省く利点よりも、現行のJavaScriptゲート実装と符号化・両視点評価の費用が大きかった。どの部分が遅延の主因かは、この診断では分離測定していない。不要ゲートの除去、真理値表に応じた式の簡略化、入力処理の改善、別の実行方式は後続候補として検討できるが、今回は変更・再測定していない。

## 技術検証と独立検算

- 全16種類のBoolean真理値表、符号化範囲、両視点の符号反転、終局符号、入力非破壊を確認した。
- 人工標本でゲート学習の勾配を有限差分と比較し、ridge回帰の既知解も確認した。
- 学習用1,024 root・2,048視点でPythonとJavaScriptの入力が一致した。
- 整数化した評価値は、論理ゲート・線形・MLPすべてでPythonとJavaScriptの差が0だった。
- 全1,152 rootのsourceを再生し、教師を同じ固定D3で再計算した。選択手・時間以外の探索統計・教師値が一致した。
- 別記述の乱数生成で、棄却を含むsource生成と選択理由を照合した。
- Pythonで誤差、時間比、戦術失敗数、判定条件を独立再集計し、JavaScriptの集計と一致した。
- 完成済みarchiveの全22ファイルをSHA-256索引へ照合した。

独立検算は計算手順を分けたものであり、独立したルールエンジン・独立した探索アルゴリズムによる真理の検証ではない。時間制限付き対局は実行も再測定もしていない。未到達の対局工程について、実戦での動作・性能を確認済みとは扱わない。

## 次に検討できること

今回の結果からは、論理ゲート型の推論実装の軽量化と、速かった線形評価器の対局検証が具体的な後続候補になる。どちらも今回の候補を後付けで救済せず、新しい候補・契約・未使用の評価集団で行う。今回の開発用データは既知データとして扱い、最終評価へ転用しない。

PBAI-P6の検証はここで完了した。公開系統はAI-GEN3を維持する。main統合、公開切替、世代昇格は行っていない。
