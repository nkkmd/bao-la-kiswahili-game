## 次に確認すること

残る確認はスマートフォン実機、複数ブラウザ、expert設定、継続操作時の応答である。PCで400ms設定を選ぶだけではスマートフォンの実測にならない。公開採用はこれらの確認結果と切替内容を基に別途判断し、P9の成功だけで公開設定を変更しない。

既知局面の実機互換性を確認するため、[検証ページ](../../../tools/engineering/browser/pbai-p9/index.html)を用意した。リポジトリのルートで次のコマンドを実行すると、この検証ページのフォルダを配信できる。

```sh
python -m http.server 8765 --directory tools/engineering/browser/pbai-p9
```

PCではlocalhost:8765を開く。同じネットワークのスマートフォンでは、配信しているPCのLANアドレスとポート8765を使う。ページの「検証を実行」を押し、タブを前面に置いて待つ。「結果を保存」でJSONを取得し、端末名、OS、ブラウザ、実行日時、画面操作で気になった点を別に記録する。この手順は公開ゲームを切り替えない。

ページは60件のWorker要求と18件の直接実行を確認する。出力のphysicalDeviceVerifiedは自動認定を避けるためfalseのままであり、実際にどの端末で操作したかは別の実機記録で裏付ける。既知の互換性試験だけで端末上の棋力を判断しない。新しい棋力測定を行う場合は別の条件固定と新規集団を用いる。
