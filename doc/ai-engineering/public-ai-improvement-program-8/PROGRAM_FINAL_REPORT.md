# PBAI-P8 — 最終報告

## 正式判断と意味

正式判断は`STRENGTH-IMPROVED-IN-FROZEN-DOMAIN`。事前固定した新規512対局で295勝217敗、勝点率57.6171875％となり、棋力・運用条件と正式な全件検算を通過した。Node/Linux、双方100ms・最大深度8の範囲で、この学習済み論理ゲート評価器をAI-GEN3の探索へ組み込むことによる棋力改善を確認した。

Programは`COMPLETE`。これは候補の正式採用や公開配備を意味しない。公開判断は`NO-RELEASE / KEEP-AI-GEN3`であり、現行の公開AIを維持する。

## 何を変更し、何を固定したか

P7は保存済み数値の0と再計算した−0を厳密比較して正式検算が停止した。P8では、保存値と再計算値が双方とも有限のnumberであることを要求したうえで、数値比較`===`を用いた。ゼロの符号差だけを同値とし、許容誤差は0、実際の数値差・NaN・±Infinity・null・非数値は拒否する。

P7の既知1局面でのゼロ符号差2比較を回帰入力に使用した。±0と正負の数値のJSON往復、最小の正数を含む数値差を拒否する負の対照も実施した。これらは既知の技術入力であり、P8の新規棋力証拠に数えていない。

候補は同じ`PBAI-C015-v1`。P6の学習済みモデル、P7の推論コード、ルール、探索機構を保持し、再学習・係数調整・候補選択は行っていない。P7の簡略化済み推論は実行時589演算、使用入力327bit、読み出し329項である。P8は新しい高速化アルゴリズムを追加した検証ではない。

## 事前固定と集団の分離

条件と依存44ファイルを、実行前にcommit `4b0cf7a662744ce1dd945213f44a1680f8d4bed5`としてGitHubへ保存した。モデルと基準AIのhash、seed、閾値は[SPEC.json](SPEC.json)を正本とする。外側の単一監視器が生成から正式検算まで連続4時間を監視し、今回の実行は1,797.287秒で完了した。

P6までの既知情報に加え、P7の全採用／棄却sourceの識別情報と、採用source系列・全704対局で訪れた局面のRAWを除外した。計67,532の識別情報行を固定し、新規seedを使用した。新規split内外でもRAW・12手prefix・全系列hashを重複排除した。

P7の成績は設計根拠として既知である。P8が独立に発想されたとは主張しない。P7より既知RAWの除外範囲が広く、新規の対象集団で検証している。標準初期局面や短い共通prefix、すべての未採用状態での合流まで独立とは主張しない。P7の対局は今回の成績に加えていない。

## 公開判断と限界

この結果は、固定モデルの論理ゲート評価器を使う探索AIが、今回の範囲でAI-GEN3を強化できることを示す。論理ゲートという方式一般が、ほかのすべての評価器より優れることを証明したものではない。

スマートフォン、ブラウザ、標準500msでの速度や棋力は未確認。公開採用を検討する場合は、実際の対象環境と設定での検証・組込み・配信確認が別途必要になる。今回の作業ではmain統合、公開切替、正式採用、AI世代昇格は行っていない。
