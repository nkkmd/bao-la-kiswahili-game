## Confirmatory center

Primary constructは**blinded cross-position principle discrimination**とする。

Stage 1ではprimary task候補を次の3-position blockとして実装準備している。

```text
C03 target A
C03 target B
matched non-C03 control
```

回答者は「同じ再利用可能なmove principleを共有する」と考える2局面を選ぶ。3つのpair候補があるためrandom-choice probabilityは`1/3`。

単一局面でのC03 matching move選択は重要だが、transferability recognitionを直接測らないためsecondaryとする。
