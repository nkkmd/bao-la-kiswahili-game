# 全閉包統合の保存結果

[RESULT.json](RESULT.json)は全fixtureの状態・完全性・解件数・保存量・hash・遮断・範囲を示す。[TECHNICAL_EVIDENCE.json.gz](TECHNICAL_EVIDENCE.json.gz)は全canonical領域、独立一致した解、元snapshotとjournalを含む。[EXECUTION.json](EXECUTION.json)は全体資源の元記録である。

[BENCHMARK.json](BENCHMARK.json)は初回12行、[PROCESS_MEASUREMENT.json](PROCESS_MEASUREMENT.json)は別契約のLinux補助12行を保持する。初回RSSの同値を含む全試行を保存し、結果を選別しない。実資源は環境依存であり、科学BFS改善や新しい完全領域を示す成果物ではない。

機械定義のfield/ID/hashは原表記を保持する。[日本語の報告](../REPORT.md)と[再現性](../REPRODUCIBILITY.md)で意味と限界を説明する。
