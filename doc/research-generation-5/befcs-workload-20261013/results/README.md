# 保存済み全workload統合の結果と証拠

[RESULT.json](RESULT.json)は8シナリオの技術結果、[TECHNICAL_EVIDENCE.json.gz](TECHNICAL_EVIDENCE.json.gz)は各Git bundleと監督記録、[CAPACITY_RESULT.json](CAPACITY_RESULT.json)は実共有容量の境界確認を保存する。[出力binding](../OUTPUT_BINDING.json)でbyte hashを照合する。

論理markerと固定byteの再生は科学sourceの生成・科学seed消費ではない。coverageのnullを0やDRAWへ変換しない。科学用freeze・host接続・別triggerが未完であり、技術合格から供給Studyを実行しない。
