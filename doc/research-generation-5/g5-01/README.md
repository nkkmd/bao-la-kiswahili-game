# G5-01 — 順位変動・価値損失の測定準備

作成日: 2026-10-12（日本時間）  
Study: `RRSVL-STUDY1`  
状態: **測定・独立遷移の技術検証合格／開発診断設計済み／新規証拠の科学実行は未開始。**

第五世代の第1段階として、探索順位の変動、選択手の変更、勝敗価値の損失、同価値内の到達手数差を別々に保存する測定基盤を確認する。既知のBao局面と人工グラフだけを使い、これらを新しい研究結果や正式検証群へ昇格させない。

採用するルール版は `BAO-RULES-V0.2.0-TAKASIA-001` である。2026-09-29のProgram計画後にtakasiaが採用されたため、RAW識別へtakasiaの対象とルール改訂を加える。過去のR-002研究は当時のルールを保持する。

## 最初のStage 0の技術検算範囲

探索はAI-GEN4で採用された固定論理ゲート評価器を使い、研究専用の深さ1・2、全root手の順位測定で比較する。時間制限や静止探索は使わない。公開expertそのものの探索設定や棋力を測った結果ではない。

JavaScriptのアルファベータ探索を、別に書いた全幅minimaxと照合する。両者は現行のルールエンジンと評価器を共有するため、これだけではBaoの全遷移が独立検証されたことにはならない。人工グラフは既存の二つの純粋な解法とPythonで確認する。takasiaの既知遷移には限定された独立計算を使うが、namua・捕獲後の蒔きを含む全ルールの独立検証は次工程の必要条件として残る。
