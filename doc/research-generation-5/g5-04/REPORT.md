# G5-04 — 三〜四手の自然終局供給の最終報告

## 結果と意味

新規128 sourceから9適格rootを得て、事前固定した8候補すべての完全閉包・厳密解を取得した。各11〜35状態・合計169状態162辺で全解が独立一致した。**3 rootで同じ勝敗価値の手の間にDTF差が見つかった。一方、勝敗価値の異なる手を持つrootは0件だった。**

G5-03では全手同価値・同DTFだったが、今回は同価値内の終局手数差を記述できた。ただし別区画・異なる対象層であり、旧方式との公平な効果比較ではない。DTF差を勝敗価値損失の変動例へ読み替えない。

実行判断は `STAGE1-SUPPLY-COMPLETE`、検算は `STAGE1-SUPPLY-INDEPENDENT-PASS`。供給と保存解の開発記述を完了した状態である。探索条件間の順位比較や正式な順位変動・勝敗価値損失の関係検証は未承認・未実施で、関係の不存在や公開AIの誤手について結論しない。

## 固定した対象と構造

`MTCS-STUDY1` / `MTCS-S1-SUPPLY-2026-10-12-v1` の[契約](CONTRACT.md)に基づき、区画50412001..50412128を一度だけ生成した。非終局mtaji・双方reserve 0・root幅2〜8の局面で、先に深さ2の全合法分岐を調べ、全終局した短期層を除外する。2手境界に非終局を残した場合にのみ、全分岐4手以内自然終局と全節点幅8以下を確認する。

勝者の向き、DTF、評価値・順位、価値差で候補を選定・補充していない。最初の構造成立rootをsourceごとに扱い、source順の最初の最大8候補を解析前固定した。最大4681状態・4680辺を実行前に保証し、別の幅優先全閉包と2解法で検算した。非終局境界を打切り評価やDRAWで補わなかった。

対象は少なくとも1本の経路が2手では閉じず、全経路が4手以内に自然終局する特殊層である。短い終局枝も含み、最適なプレイでのDTFが必ず3〜4になる層ではない。一般局面・長期探索の代表として扱わない。
