最終証拠は、Mの停止・完了記録、固定対象Dとそのhash、Rの実行内保存ACK、独立検算可能なmanifest/sequence、必要なOS終了証拠を役割別に定義する。親やOS manager自身の終了を、その同じprocessが終了後に外部保存する条件は課さない。一方、Mの子停止確認や保存receiptを省略したり、事後にDが見つかったことを実行内ACKへ変換したりしない。

RをMの20分の外へ置く案は、従来の同一時計内保存の条件からの変更である。Rの締切、M停止後の状態不変性、保存失敗時の終了分類を採用前に固定する。何をローカル保持し何を外部保全するかも対象一覧へ明記し、最終証拠を無言で減らさない。
