# 技術結果の入口

RESULT.jsonとTECHNICAL_EVIDENCE.json.gzは科学用遷移・microstate/抽象証明の技術結果である。CODEC_RESULT.jsonとTECHNICAL_RAW.binは422技術境界RAWの可逆保存結果で、標準開始からの新規科学コーパスではない。EXECUTIONはローカル資源記録で、CI環境の資源値と同一であることを要求しない。

各入力manifestとOUTPUT_BINDINGからソース・固定fixture・結果のバイトを辿れる。[報告](../REPORT.md)で未知、構築/抽象例の範囲、技術RAW射影と正式証拠の遮断を説明する。旧Science結果へ新しい解析を追加しない。
