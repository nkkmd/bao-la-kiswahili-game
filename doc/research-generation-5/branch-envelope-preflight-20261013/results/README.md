# 固定fixture技術証拠

本ディレクトリは、科学sourceを生成しないpreflight結果を保存する。結果の意味と限界は[報告](../REPORT.md)を参照する。

- RESULT.json: 判断、10 source/7 closure fixture、17保存bundle、遮断数、実容量境界。
- TECHNICAL_EVIDENCE.json.gz: 全source trace/screen、全保存辺・停止witness・解、bundle index/全片。
- EXECUTION.json: 初回技術runのNode・時間・process peak RSS。

ID・状態token・hash・JSON fieldは機械定義として保持する。抽象fixtureの候補をBaoの科学候補へ昇格させず、科学seed消費は0件、正式関係は未登録・未実行のままである。
