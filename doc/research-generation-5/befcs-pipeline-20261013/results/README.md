# 結合pipelineの固定技術証拠

[開発中の未合格診断](DEVELOPMENT_DIAGNOSTIC.json)を保持する。現行の9シナリオはActions artifactへ保存し、取得検算後にCI出力bindingを別固定した。全結果は科学seed消費0・科学leaseなし・未登録/未実行で、技術fixtureの完了と科学的な解釈完了を分ける。

[実cgroup結果](CI_RESULT.json)・[全圧縮証拠](CI_TECHNICAL_EVIDENCE.json.gz)・[receipt](CI_RECEIPT.json)・[CI出力binding](CI_OUTPUT_BINDING.json)は取得検算済みの追加記録である。全9シナリオの技術合格を確認したが、科学全体の実行認可ではない。

強制終了やmirror失敗の保存prefixを完全証拠へ昇格せず、未知をDRAW/0/敗北へ変換しない。終了mirror失敗でもローカルartifactへGit registryを保持する。
