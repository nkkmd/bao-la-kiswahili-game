# 第五世代研究 — 探索順位の変動と厳密価値の損失

作成日: 2026-09-29  
状態: **G5-01の測定・独立遷移の技術検証合格／新規証拠の科学実行は未開始**  
対象: Bao Research Generation 5

## 何を調べるか

探索条件を変えたときに手の順位が変わることと、選ばれた手が厳密解に照らして不利になることは別の現象である。第五世代では、新たに選定した完全解析可能な局面を対象に、両者の関係と成立する範囲を調べる。

第四世代のG4-03は合法手幅と順位変動の関連が一部の新しい領域へ移ることを確認した。しかし、順位変動が悪手を意味するかは判定していない。G4-05とG4-09の固定8領域は厳密解と探索の照合を可能にしたが、一般局面の正答率を示さない。本研究は、それらの判断を変更せず、新しい問いと証拠で進める。

## 現在の位置

2026-10-12のユーザーの着手指示に基づき、[G5-01](g5-01/README.md) / `RRSVL-STUDY1` のStage 0技術契約を固定した。現行takasiaルールのRAW識別と、既知fixture限定の順位・価値損失測定、独立検算、中断復帰を確認し、ローカル・ActionsでStage 0技術検証が合格した。続く[独立遷移の技術検証](g5-01/transition/REPORT.md)も固定40局面・411辺で合格し、[新規局面の開発診断設計](g5-01/DEVELOPMENT_PLAN.md)を具体化した。正式評価対象集団、科学的seed、判断閾値、新規領域の資源上限は未固定であり、新規証拠による科学実行は開始していない。

研究の結果が確認・非確認・推定不能のいずれでも、あらかじめ定める終了条件で研究として閉じる。公開AIの採用、勝率、応答時間は本研究の評価指標にしない。
