# Checkpoint — 捕獲分岐形成過程

日付: 2026-07-31  
実験: E-014  
状態: 完了

## 目的

捕獲分岐急拡大5区間について、候補時点から8ply後までのどの盤面変化が捕獲手数ピークと併存するかを分解する。

## 対象

- 5候補区間
- 3アーキタイプ
- `22807aff1baf`: 1区間
- `6b364e603366`: 1区間
- `9f778d512ae1`: 同一軌跡3区間

## 方法

各候補局をpilot-v2の固定設定から決定論的に再生成した。

各plyについて以下を記録した。

- 捕獲手数
- 合法手数
- 手番側・相手側の前列占有pit数
- 手番側・相手側の再利用可能pit数
- 手番側・相手側の最大捕獲可能量
- 前列種数
- reserve
- nyumba所有
- phase

捕獲手数は各plyの手番側に属するため、盤面指標も各plyの手番側／相手側基準で計算した。候補時点のプレイヤーへ固定する初回方式は主体がずれるため撤回した。

## 結果

| 指標 | 結果 |
|---|---:|
| 捕獲手数ピークまで | 平均1.8ply |
| 候補側と同じプレイヤーでピーク | 4/5 |
| 捕獲手数変化 | 平均+0.8手 |
| 手番側最大捕獲可能量 | 平均+3.0粒 |
| 相手側最大捕獲可能量 | 平均-1.2粒 |
| phase変化 | 0/5 |
| 手番側nyumba消失 | 1/5 |

## 候補別

- `22807aff1baf`: 候補時点の捕獲手数9が窓内ピーク。追加増加なし。
- `6b364e603366`: 3ply後に7→8手。手番側最大捕獲可能量+6粒、相手側-3粒。手番側nyumba消失。
- `9f778d512ae1`: 2ply後に8→9手。手番側最大捕獲可能量+3粒、相手側-1粒。同一軌跡3区間で再現。

## 解釈

捕獲分岐急拡大はphase移行では説明されない。候補近傍で、手番側の最大捕獲可能量が増え、相手側が減る非対称化を伴う。

ただし、捕獲手数の追加増加は平均+0.8手であり、分類の大きなcapture deltaは候補前基準値との比較で生じる。また、5区間中3区間が同一軌跡のため、区間平均を独立5例とは扱わない。
