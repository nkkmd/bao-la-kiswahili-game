## 調べられることと限界

固定した序盤分布と探索条件の中で、先後差の方向・大きさ・不確実性、探索強度による変化、座席依存、初手や局面進行との関連を調べます。標準初期局面の決定的対局は診断として扱い、反復を独立標本に数えません。

このリポジトリのR-002実装（takasia未実装、連続種まき上限あり）に対する条件付き自己対局です。熟練者対局、全ルール流派、理論的な先手必勝・後手必勝・均衡を証明しません。
