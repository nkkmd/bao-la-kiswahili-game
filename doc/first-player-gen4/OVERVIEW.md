# 追加研究の概要

**AI-GEN4の公開expert同士では、静的評価の上位3手から序盤を作る条件で先攻有利が示されました。一方、全合法手から均等に序盤を作る条件では方向を確定できませんでした。Bao一般の先攻・後攻差は未確定です。**

従来研究では、同一棋譜を繰り返しても独立した証拠にならないこと、探索深度・序盤分布で結果が変わることが問題でした。今回の研究は新規seed、2つの序盤分布、座席交換、4つのAI条件を事前に固定し、本試験16,384局を含む全17,768局を実行しました。

公開expertの先攻勝率は、全合法手から序盤を作る条件で53.17%（97.5%区間49.21〜57.11%）、静的評価上位3手から作る条件で56.88%（52.31〜61.51%）でした。後者は当該条件内の先攻有利、前者は未確定です。多様化なしの標準初期局面診断では全条件で後攻が勝ちましたが、独立した勝率標本には数えていません。

全対局が決着し、正式3領域の全棋譜再生と別言語再集計が合格しました。ルールと不確実性の完全な独立実装検証は行っていません。条件付き自己対局の研究であり、理論的な必勝・均衡や人間の実戦を証明するものではありません。

[最終報告](FINAL_REPORT.md)で結果と限界を、[事前計画](PROTOCOL.md)で凍結した条件を、[再現手順](REPRODUCIBILITY_INDEX.md)で証拠を確認してください。研究は完了し、main統合済みです（PR #178）。
