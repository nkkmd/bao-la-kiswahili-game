# AI-GEN4先攻・後攻差追加研究 — 最終報告

研究ID: `FPA-GEN4-STUDY1-20261003-v1`

完了日: 2026-10-04

状態: **予定した全17,768局と最終検証が正常完了。研究ブランチへ結果を保存。main統合済み（PR #178）。**

## 1. 結論

**AI-GEN4の公開expert同士では、静的評価の上位3手から序盤を作る条件で先攻有利が示されました。一方、全合法手から均等に序盤を作る条件では方向を確定できませんでした。Bao一般の先攻・後攻差は未確定です。**

この研究が推定するのは、標準初期配置から指定の方策で8手を進め、その後を同じAIが対戦した場合の、開始時の先攻の勝率です。両者が最初の1手から最善手を指す理論的ゲームの価値や、人間の実戦勝率を推定したものではありません。

## 2. 主要結果

主要条件`G4E2000`は現行の公開expert経路、最大深度12、1判断2,000msです。各方策は1,024開局スロットを座席交換して2,048局にします。座席ペアと重複開局系列をまとめたクラスタbootstrapを10,000回行い、2つの主要領域について事前規定の97.5%区間を使います。

|8手序盤の生成方策|先攻勝|後攻勝|未決着|先攻勝率|97.5%区間|正式判断|
|---|---:|---:|---:|---:|---|---|
|全合法手から一様選択|1,089|959|0|53.17%|49.21〜57.11%|`INCONCLUSIVE`|
|静的評価上位3手から一様選択|1,165|883|0|56.88%|52.31〜61.51%|`FIRST-ADVANTAGE-WITHIN-DOMAIN`|

`top3`では50%から+6.88ポイントで、区間の下限も50%を上回ります。`FIRST-ADVANTAGE-WITHIN-DOMAIN`は、この序盤分布とAI条件内で先攻方向を支持する判断です。`top3`は着手直後の静的評価順位であり、探索で保証した最善3手や熟練者の自然な序盤分布ではありません。

`uniform`では+3.17ポイントですが、区間が50%を含むため`INCONCLUSIVE`です。これは「互角が証明された」という判断ではありません。区間全体が事前の実用許容幅47〜53%にも収まらず、実用的均衡も確定できません。異なる方策を合算した勝率をBao全体の勝率として使いません。

## 5. 多様性・座席・実行状態

正式試験の各方策1,024スロットには、`uniform`で859種類の局面・878種類の開局系列、`top3`で631種類の局面・676種類の開局系列がありました。復元抽出による頻度を保持し、重複を削除して分布を変えていません。クラスタは開局着手列と状態の組で定義され、異なる着手列が同じ状態に到達する場合は別系列です。別系列間の局面共有に対する追加の区間解析は実施していません。

固定深度条件ではSouth先攻とNorth先攻の勝敗集計が完全一致しました。公開expertでは、先攻勝数が`uniform`で546対543、`top3`で586対579でした。最大0.68ポイントの座席別勝率差であり、時間制限による探索の揺れを含みます。座席無偏りの証明や、別runnerで同じ棋譜になる保証ではありません。

全17,768局は`front-empty`または`no-move`で決着し、未決着は0局でした。固定深度4・6はいずれも指定深度を完了し、安全時間上限による打切りは0件でした。公開expertで記録された探索タイムアウトは、時間内に完了した反復深化の結果を使う通常動作であり、対局未決着とは区別します。正式expertの平均完了深度は約10、平均探索時間は約1.55秒でした。

## 6. 検証と解釈の限界

Node集計器は全域のID完全性、固定ソースhash、開局のseed再生成、通常ルール遷移による棋譜再生を検証しました。予備352局、本試験16,384局、感度分析1,024局の3領域はいずれも`VERIFIED-COMPLETE-DOMAIN`です。

Pythonの別実装による勝敗・件数・手数・局面多様性・未決着上下限の再集計も、3領域すべて`INDEPENDENT-RECOUNT-PASS`でした。ただし`rulesIndependent = false`、`uncertaintyIndependent = false`です。完全に独立したルールエンジンや、区間計算の別実装検証は行っていません。診断8局は別の記録として保持し、正式勝率へ混ぜていません。

クラスタbootstrap区間は、凍結した有限コーパスと条件付き自己対局に対する近似的な区間です。全開局・全AI・人間・完全プレイへの保証ではありません。R-002実装のtakasia未実装と連続種まき上限という範囲も維持します。AI-GEN4による序盤生成と継続評価の共有が方策依存に影響する可能性はありますが、その原因をこの試験だけで断定しません。
