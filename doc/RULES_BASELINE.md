# 採用ルール基準

Version: 1.0.0  
Status: Active  
更新日: 2026-07-31

## 1. 目的

この文書は、`bao-la-kiswahili-game` が採用する Bao la Kiswahili のルール基準、ゲーム実装との関係、既知の差異、更新手順を一か所に記録する。

ルールに依存する設計書、戦略資料、AI技術文書、ベンチマーク、先攻・後攻差研究、定石研究その他の研究成果は、特に断りがない限り、この文書で定義する基準と当該時点のルールエンジンを前提とする。

## 2. 外部の参照基準

本ゲームの実装上のルール基準は、次の日本語ガイドである。

- リポジトリ: [`nkkmd/bao-la-kiswahili-ja`](https://github.com/nkkmd/bao-la-kiswahili-ja)
- 公開版: `v0.1.0-draft`
- 採用基準: `R-002`
- 固定参照コミット: [`1179267b1f19b27a2138791253f2cb9cbfe98c14`](https://github.com/nkkmd/bao-la-kiswahili-ja/tree/1179267b1f19b27a2138791253f2cb9cbfe98c14)

`bao-la-kiswahili-ja` は公開ドラフトであり、Bao全体に対する公式規則または大会規則そのものではない。大会、地域、対局団体などが別の規則を明示している場合は、その規則を優先する。

このため、本リポジトリの文書では、根拠なく「公式ルール準拠」と表現せず、原則として「採用ルール基準に基づく」「`bao-la-kiswahili-ja` の基準を実装する」などと表現する。

## 3. ルール基準とゲーム実装の関係

役割を次のように分離する。

| 対象 | 役割 |
| --- | --- |
| [`bao-la-kiswahili-ja`](https://github.com/nkkmd/bao-la-kiswahili-ja) | 人が読むルールの参照基準 |
| [`public/engine.js`](../public/engine.js) | 合法手生成と盤面遷移における実行時の Single Source of Truth |
| [`test/`](../test/) | 実装されたルール挙動の回帰検証 |
| 研究文書・成果物 | 特定時点のルールエンジンと実験条件から得た結果の記録 |

ルールエンジンはゲーム内部の判定を一元化するが、Baoのルールそのものの一次資料ではない。人間プレイヤー、コンピュータAI、ベンチマーク、局面解析、研究ツールは、同じルールエンジンを利用する。

## 4. 現在の実装範囲

現在のルールエンジンは、主に次を実装する。

- 捕獲義務
- namua
- mtaji
- 連続種まき（relay sowing）
- nyumba
- 捕獲
- 合法手生成
- 勝敗判定

実装範囲の詳細と実際の挙動については、[`public/engine.js`](../public/engine.js) と関連テストを正とする。

## 5. 既知の差異と実装上の制約

### 5.1 `takasia`

検証に使える完全な出典局面がまだ確認できていないため、現在のゲームでは `takasia` を適用していない。

### 5.2 連続種まきの安全上限

実装上、終わらない対局や処理停止を防ぐため、連続種まきには安全上の上限を設けている。これはブラウザ実装を保護するための制約であり、Baoの通常ルールとして追加した規則ではない。

### 5.3 研究結果への影響

合法手生成、nyumba、捕獲、終局条件などを変更すると、AI評価、探索結果、開局木、先攻・後攻差、定石候補、保存済み研究成果が変わる可能性がある。

したがって、過去の研究結果は、その成果物に記録されたソースコミット、ルールエンジン、設定、seedなどに対応する結果として扱い、ルール変更後へ自動的に一般化しない。

## 6. 更新方針

[`bao-la-kiswahili-ja`](https://github.com/nkkmd/bao-la-kiswahili-ja) の `main` ブランチに変更が入っても、本ゲームへ自動的には取り込まない。

ルール基準を更新する場合は、次の順に進める。

1. 旧固定参照コミットと新候補コミットの差分を確認する。
2. ゲーム実装へ影響する規則を特定する。
3. `public/engine.js` と関連コードを更新する。
4. 正常系、境界条件、回帰ケースのテストを追加または更新する。
5. 既存テストを実行する。
6. 必要に応じてAIベンチマークと研究を再実行する。
7. この文書の公開版、採用基準、固定参照コミット、既知の差異を更新する。
8. ルート `README.md`、ゲーム画面、主要設計・研究文書の参照を同期する。

## 7. 主要文書での参照方法

ルールに依存する主要文書では、必要に応じて次の注記を使用する。

```markdown

> 本文書は、[`bao-la-kiswahili-ja`](https://github.com/nkkmd/bao-la-kiswahili-ja)
> `v0.1.0-draft` の `R-002` を基準とする本リポジトリのルール実装を前提とする。
> 実装範囲、既知の差異、固定参照コミットは
> [`RULES_BASELINE.md`](RULES_BASELINE.md) を参照する。
```

研究文書でソースコミットを個別に記録している場合は、その記録を優先し、この文書へのリンクを補助的な説明として扱う。
