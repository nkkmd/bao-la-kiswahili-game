## 1. このStudyについて

`PSRRE-STUDY1`は、`G2-10 / UMSSR-STUDY1`と`G2-11 — Long-Horizon Strategic Transition Structure Study 1`の間に置かれた、新規・prospective・独立のstrategic representation prerequisite Studyである。

正式英語題目:

**Prospective Strategic-Regime Representation Eligibility Study 1**

本Studyには新しい`G2-xx` agenda sequence labelを付けない。Research Generation 2のcore agenda labelsは`G2-01..G2-12`のまま維持する。

## 2. 何を調べるか

中心課題は、G2-11のlong-horizon transition研究へ入力候補として渡せるstrategic-state / regime representationを、新しいfresh evidenceとprospective contractの下で構築・held-out検証できるかである。

G2-10の40-feature / deterministic K-means contractを緩和・拡張・再定義して救済する研究ではない。
