## 5. Canonical structured-data digest contract

Every scientific digest of an object or array must be computed as:

```text
SHA256(UTF8(CANONICAL_JSON(value)))
```

Canonical JSON rules:

- arrays preserve array order;
- object keys are sorted lexicographically, except all-numeric key sets are sorted numerically;
- integers/rational numerator and denominator strings are serialized exactly;
- `undefined`, prototypes, runtime metadata and iteration-order artifacts are excluded from scientific cores;
- no call to a low-level string digest may accept an object/array directly.

Production and independent implementations must each implement canonical serialization independently. Stage 0 must compare both implementations against a third small reference serializer for structured nested arrays/objects and must execute the real technical candidate-selection path through candidate-core digest generation.

Any structured digest disagreement or non-string low-level digest call is `TECHNICAL-INVALID`.
