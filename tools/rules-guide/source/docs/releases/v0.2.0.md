# v0.2.0 — 正式公開前の検証版

Bao la Kiswahili 日本語完全ガイドの検証版です。`v0.1.0-draft`以降のtakasiaの正式採用、主要規則の資料照合、教材の修正をまとめました。ガイド全体の正式版`v1.0.0`に向けて、採用規則と残る制約を確認できる版として公開します。

## 主な変更

- **takasiaを本書の規則として正式採用。** 原典と著者の解説を照合し、成立条件・例外・停止処理を本文、辞典、FAQへ反映しました。64個の完全局面E30と全4応手を検証しています。
- **主要規則26項目を資料と照合。** mtajiの16個以上の穴からのtakata、合法手なしによる敗北、nyumbaの所有と機能の違いを整理しました。nyumbaで捕獲手を止める選択には、到達後6個以上の条件を明記しました。
- **教材と図版を修正。** 完全局面V01〜V04を追加し、蒔く個数・方向、nyumbaの状態を示すSVGを修正しました。公開用SVG12点を描画確認しました。
- **検証記録と検査手段を追加。** 採用根拠、資料差、未解決事項を記録し、局面計算とリンク・連番・図版参照等の検査スクリプトを整備しました。

## 収録内容と確認範囲

リポジトリ内のMarkdown本文とSVGを提供します。第00〜10章、用語辞典40項目、FAQ50問、戦術入門、規則確認用局面例E01〜E32、検証用完全局面V01〜V04を収録しています。PDF・EPUB・Webサイト・印刷版は今回の提供物に含みません。

3本の検証スクリプトと差分検査を実行しました。局面計算は限定された確認例を対象とし、全規則を実装したエンジンや対局全体の再生ではありません。実戦由来のV02で確認した範囲は冒頭2手番です。

## 既知の制約

- Bao競技者・mancala研究者による外部レビューは未実施です。現行の大会運用や対人裁定も未確認です。
- 開始前に5個のnyumbaへ手元の1個を加える境界の処理は、確認が残っています。
- 終わらない手について、資料の周期218回と再計算228回の差が未解決です。この再計算例は教材に採用していません。
- 第11章「Bao la kujifunza」は構成案であり、完成したルール本文ではありません。

本リリースはGitHubの**Pre-release**として提供します。`v1.0.0`には、正式版の収録範囲・公開形式の確定、外部レビュー、RCの通読が引き続き必要です。大会や地域で明示された規則がある場合は、そちらを優先してください。
