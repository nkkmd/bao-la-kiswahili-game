## 正式版の位置づけ

`v1.0.0` は、Bao la Kiswahili（ザンジバル版）について、本書が採用する規則、資料間の差、未確定事項を読者が区別でき、日本語のルールブックとして一貫して通読できる版とする。

正式版は、すべての地域差や研究上の疑問が解消されたことを意味しない。解消できない論点は、採用判断、根拠、適用範囲を明記する。根拠を確認できない内容は、正式ルールとして断定しない。

## リリース判定の区分

各作業は次の区分で判定する。

- **必須**: 未完了の場合は `v1.0.0` を公開しない
- **推奨**: 可能な限り正式版へ含めるが、未完了理由と今後の扱いを明記すれば延期できる
- **将来課題**: 正式版公開後の改訂で扱える
