## 採用する規則

自分のmtajiのtakataを終えた盤面で、相手に捕獲手がなく、同じ盤面で自分が指すと仮定した最初の蒔きの捕獲対象が相手前列の1穴だけなら、その穴を相手の次のtakataで空にできなくする。数えるのは捕獲対象穴であり、開始穴・方向の組合せではない。

ただし対象が1個だけの穴、前列の唯一の占有穴、前列の唯一の2個以上の穴、所有中nyumbaなら適用しない。所有を失ったnyumbaの位置は通常穴である。

相手は対象穴から始めたり、その中身をrelay sowingで取り上げたりできない。蒔きの最後の1個が対象穴へ入れば必ず停止し、途中の通過では通常どおり1個を加える。nyumbaから始めた蒔きにも同じ停止規則を適用する。制約の期間は次の相手の1手だけである。

## 資料と採用判断

参考文献番号とURLは[REFERENCES.md](../REFERENCES.md)に対応する。頁番号は印刷頁である。

| 資料 | 確認箇所 | 判断に用いた内容 |
| --- | --- | --- |
| R-001, de Voogt (1995) | pp. 41–43（PDF pp. 52–54） | 成立条件、対象穴の例外、最後の1個での停止、途中通過、nyumbaの所有状態、競技者間の異説 |
| R-006, de Voogt (2001), Issue 7 | p. 25（PDF p. 27） | 後年の著者解説、1個だけの穴の例外、mtaji初期に所有中nyumbaが残る説明 |
| R-002, Donkers (2003) | p. 167, §4.1(a–c) | 原典から形式化した条件と停止処理。原典と独立した聞き取りとしては数えない |
| R-009, K.I.B.A. 英語規則 | §4.5 | クラブ運用の説明と64個の数値局面。R-008と同系統で、独立した現地一次資料ではない |

「1個だけの穴は対象外」はR-006の明示的な説明を採用した。R-001・R-002の例外一覧には同じ明示がなく、全資料が一致する項目としては扱わない。

R-001, pp. 42–43は、nyumbaから始めた蒔きなら対象穴でも継続できるという歴史的異説を記録する。同書には複数の競技者と著者による否定があり、後年のR-006・R-002は開始元にかかわらず対象穴で止まる規則を示す。本書では継続例外を採用しない。1995年の記録を現在の全大会の統一裁定と読み替えることもしない。

## 完全局面と独立検証

R-009掲載の全32穴が指定された64個の局面をE30へ収録した。mtaji、両者の手元0個、Northの手番、両者のnyumba所有なしを指定した。Northのnyumba位置a5に10個あっても、所有状態を失っているため通常穴である。

検証は[tools/verify_takasia.py](../../tools/verify_takasia.py)で再現する。Python標準ライブラリのみを使い、リポジトリのルートで次を実行する。

```sh
python3 tools/verify_takasia.py
```

確認した内容:

- 逆算した直前局面でSouthに捕獲手がなく、A7の2個をA6・A5へ蒔くtakataで掲載局面になる。
- 掲載局面でNorthに捕獲手がなく、仮想Southの捕獲対象がa4だけで、対象除外の条件に当たらない。
- Northの合法な全4応手を停止まで蒔き、蒔きの回数が順に1・5・2・10回、a4の最終個数が2・5・2・6個となる。
- a8から紙面右向きの応手は、5回目の蒔きがa4で止まる。対象穴の途中通過では停止せず、中身を取り上げない。
- 全応手で64個を保存し、Southにa4を捕獲する手が残る。

直前のSouth局面と手は本プロジェクトの作例であり、出典の実戦記録ではない。初期配置からの到達可能性や最善性は検証していない。スクリプトはこの局面の検証用で、namua、捕獲後の再投入、すべてのnyumba機能、終局を実装するゲームエンジンではない。

R-009掲載の別の反例は合計56個である。前列の「唯一の2個以上の穴」という例外の局所説明には使えるが、mtajiの完全局面としては使わず、不足分を推測で補わない。

## 原典の実戦適用記録と残る課題

R-001, p. 151（PDF p. 162）には1994-10-17のRamadhan（South）対Kijumbe（North）の記録がある。34手目のSouthのB6Rでa2を対象とするtakasia、36手目のSouthのA7Rでa1を対象とするtakasiaが記され、Northの応手が対象穴で止まる説明がある。これは実戦での適用記録の確認であり、全盤面の再構成や全対局の再生の検証ではない。

残る課題は、原典棋譜の全盤面再生、各例外の出典付き完全局面、戦術評価、現地・大会の現在の運用、語形と語源、takasia以外の規則の項目別照合である。[TODO](../TODO.md)で管理する。
