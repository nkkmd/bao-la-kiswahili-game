# 図版スタイル

## 目的

盤面の向きや記号が図ごとに変わらないよう、すべてのルール図に共通する表現を定める。

## 盤面の向きと座標

- Northを上、Southを下に置く。
- 上からNorth後列 `b`、North前列 `a`、South前列 `A`、South後列 `B` とする。
- Southから見た穴番号は左から右へ1〜8とする。
- Northから見た穴番号も本人の左から右へ1〜8とするため、紙面上では右から左へ1〜8となる。
- 真向かいの前列穴は `A1` と `a8`、`A2` と `a7`、……、`A8` と `a1` のように対応する。
- Southのnyumbaは `A5`、Northのnyumbaは `a5` とする。

座標の根拠は `docs/REFERENCES.md` のR-002 Appendix C, Figure C.2による。公開前にde Voogt原典と再照合する。

## 基本記号

| 対象 | 表現 |
| --- | --- |
| 通常の穴 | 円 |
| nyumba | 角丸の正方形 |
| kichwa | 太い二重枠 |
| kimbi | 点線の外枠 |
| kete | 穴の中央に個数を数字で表示 |
| 蒔く方向 | 実線の矢印 |
| 捕獲元から捕獲先 | 太い破線の矢印 |
| 選択可能な経路 | 細い破線の矢印 |
| 操作対象 | 枠と淡い背景色の両方で強調 |
| 操作禁止 | 斜線。色だけで禁止を示さない |

kichwaはkimbiに含める説明もあるため、両者を同時に示す図では凡例を必ず付ける。

## 色

- 盤と通常穴: 無彩色を基本にする。
- North: 青系 `#2563EB`。
- South: 橙系 `#EA580C`。
- 操作対象: 黄系 `#FACC15`。
- 禁止・警告: 赤系 `#DC2626`。

色覚差や白黒印刷に備え、色だけに意味を持たせない。枠線、線種、文字ラベルを併用する。

## keteの個数

- 原則として穴の中央へ算用数字で示す。
- 0個は空欄ではなく、必要な図だけ `0` と表示する。
- 個々の粒を描くのは、1個ずつ蒔く動作を示す拡大図に限る。
- 16個以上でも読めるよう、数字の桁数で穴サイズを変えない。

## 手順図

- 左から右、または上から下へ時間が進む。
- 各コマに「開始」「捕獲後」「蒔き終わり」などの短い状態名を付ける。
- 1枚で扱う判断は1つに絞る。
- 操作前後で盤面の向きと縮尺を変えない。
- 省略した穴がある場合は、省略記号と注記を置く。

## ファイル形式と命名

- 公開用の基本形式はSVGとする。
- 写真や手描きイラストが必要な場合はPNGまたはWebPを使う。
- ファイル名は `fig-章番号-連番-内容.svg` とする。
- 例: `fig-02-01-board-overview.svg`
- 図番号は `図2-1` のように章番号と章内連番で表す。

## ライセンスと代替テキスト

- 自作図は「自作」と記録する。
- 外部資料を参照した場合は、盤面データの根拠と画像表現の出典を分けて記録する。
- 公開時は本文に、図の目的と結論を含む代替テキストを付ける。
- 装飾的な説明ではなく、穴番号、個数、矢印の開始・終了を言葉にする。
