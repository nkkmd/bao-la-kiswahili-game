# 図版設計

作業中の図版、構成案、図番号の検討を置く。公開用の完成画像は `assets/images/` に配置する。

図版ごとに、本文の参照先、図番号、ファイル名、出典、ライセンス、自作かどうかを記録する。

## 設計文書

- [図版台帳](FIGURE_CATALOG.md): 必要な図、掲載章、制作状態
- [図版スタイル](FIGURE_STYLE.md): 盤面座標、色、記号、アクセシビリティ
- [盤面座標の試作図](board-coordinate-system.svg): 穴番号と向きを検証する作業用SVG

## 制作フロー

1. 図版台帳で目的と掲載章を決める。
2. 説明対象となる開始局面と終了局面を資料で検証する。
3. `docs/figures/` で作業図を作る。
4. 本文なしでも読み取れるか確認する。
5. 完成版を `assets/images/` へ配置し、本文から参照する。
6. 台帳へ出典、ライセンス、制作状態を記録する。
