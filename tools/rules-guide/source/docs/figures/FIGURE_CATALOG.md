## 台帳項目の追加ルール

図を追加するときは、少なくとも図番号、掲載章、公開ファイル名、目的、必要な状態、根拠、状態を記録する。公開可へ変更するときは、次も追記する。

- 制作者
- 制作日・更新日
- ライセンス
- 自作かどうか
- 本文の参照箇所
- 代替テキスト
