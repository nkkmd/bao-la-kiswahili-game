# Bao la Kiswahili 日本語完全ガイド プロジェクトロードマップ

> Repository: **bao-la-kiswahili-ja**
>
> 日本語で最も正確かつ読みやすい **Bao la Kiswahili（ザンジバル版）** のルールブック・リファレンス・教材をオープンソースで制作する。

---

# プロジェクト概要

本プロジェクトは、Bao la Kiswahili の正式ルールを学術資料・競技ルール・一次資料をもとに整理し、日本語話者が安心して学べる包括的なガイドを作成することを目的とする。

目標は単なる翻訳ではない。

* 初心者向け教材
* 正式ルールブック
* リファレンス
* 用語辞典
* 戦術入門

これらを一体化した「日本語版 Bao la Kiswahili 完全ガイド」を制作する。

## リリース状態

初回公開は、未確認事項を明示したドラフト版 `v0.1.0-draft` とした。現在は、正式公開前の検証版 `v0.2.0` の公開準備を整えている。提供形式はMarkdownとSVGで、GitHubではPre-releaseとして公開する。タグとReleaseは未作成である。

この版は完成版ではない。2026-10-08にR-001全文を取得し、takasiaを原典照合・完全局面検証のうえ正式採用した。同日、他の主要規則も項目別に照合した。5個のnyumbaからの開始境界、外部の競技者・研究者レビュー、収録範囲・公開形式、Bao la kujifunzaの基準資料確認などは残っている。大会や地域で明示された規則がある場合は、そちらを優先する。

正式版 `v1.0.0` に向けた条件と作業計画は、[正式版リリースロードマップ](RELEASE_ROADMAP.md)で管理する。

## Phase 5

実例集

局面図を多数追加する。

目標

30〜50例。

### 作例方針

* 実在の棋譜と、規則確認用に構成した例を区別する
* 完全局面を検証できない場合は、判定に必要な穴だけを示す部分局面とする
* 省略した穴を空穴と解釈させず、未指定であることを明記する
* 各例に根拠資料と確認状態を付ける
* 資料から安全に導けない完全局面や手順は、例数のために補わない

### 完了条件

* 30例以上の局面例が一意の番号で収録されている
* 盤・初期配置、namua、mtaji、捕獲、relay sowing、nyumba、終局を横断している
* 各例が作例か採録例かを判別できる
* R-002・R-003一致の規則と、R-002単独の形式規則が区別されている
* 未検証の完全局面が確定例として掲載されていない

**状態: 完了（32例。2026-10-08現在は部分局面31例、出典付きtakasia完全局面E30の1例）**

# 品質目標

完成版は以下を満たすことを目標とする。

* 正式ルールと矛盾しない
* 初心者でも読める
* 図だけでも理解できる
* 用語が統一されている
* 地域差を明記している
* 出典が明確である
* 継続的な改訂が可能である

`v0.1.0-draft` と `v0.2.0` は完成版の品質達成を宣言するものではない。資料上の制約と未確認事項を公開し、外部レビューと継続的な検証を受けるための版と位置づける。v0.2.0の変更点と制約は[説明本文](releases/v0.2.0.md)にまとめる。
