# Bao la kujifunza

## この章の目的

Baoの基本的な蒔きと捕獲を学ぶための簡略版を、Bao la Kiswahili本編と混同しない形で紹介する。

- 対象読者: 簡略版から練習したい初心者と指導者
- 扱う範囲: 簡略版の導入と本編との差。ザンジバル版本編の詳細は扱わない
