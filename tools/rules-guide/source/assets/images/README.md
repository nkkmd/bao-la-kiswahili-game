# 公開用画像

ガイドで使用する完成済みの図版、イラスト、アイコンを配置する。

画像を追加するときは、対応する本文または `docs/figures/` の設計メモに、出典、ライセンス、自作かどうかを記録する。

## Phase 3公開図版

盤、初期配置、namua、mtaji、捕獲、relay sowing、nyumba、終局を説明する自作SVGを配置している。図番号、根拠、代替テキスト、制作情報は `docs/figures/FIGURE_CATALOG.md` を参照する。
