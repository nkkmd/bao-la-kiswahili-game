## 停止時点で確認できたこと

停止した要求のIDは`pilot-v2-pair-0-game-0-ply-26`である。合法な6候補を含む入力がHTTP 200で約382ms後に返ったが、キットは`invalid-response`として拒否した。入力を基準エンジンから再生成して一致を確認し、棋譜26手の合法性と停止局面も再生して確認した。以前の予備試験・遅延診断の記録は保持されている。

## 元のキットの記録不足

元のAPIクライアントは、応答検証に失敗すると、失敗した項目と候補別の数値を保存せず、`invalid-response`という区分だけを残していた。そのため、今回の不合格が、確率の合計、項目不足、選択候補と最大確率の不一致、値の範囲などのどれによるものだったかは特定できない。この記録不足は実験キット側の問題である。

[公式のChoice仕様](https://docs.typesafe.ai/primitives/choice)では、全候補の確率、最大確率の候補、0〜1のconfidenceが返る。確率の合計は1と説明されている。元の検証は合計と1の差を0.002未満に制限している。複数の丸められた数値の合計がこの条件から外れた可能性はあるが、今回の実際の数値が残っていないため、原因とは断定しない。

この診断では入力と検証条件を変えない。新たに同じ入力を1回だけ送り、検証に必要な数値と失敗項目を記録する。未知の文字列、APIキー、認証ヘッダー、エラー本文は保存しない。

新しい回答は過去の応答の復元ではない。同じ入力でも回答が変わることがあり、1回で異常が再現する保証はない。正常に返った場合も、過去の不合格を正常へ書き換えたり、原因が解消したと判断したりしない。

## 停止状態での明示許可

既存の予算台帳の`halted: true`は、元のキットの応答検証エラーにより、有料実行を停止した状態である。この診断はその停止を解除しない。対局コマンドは引き続き送信できない。

原因を調べるための追加通信に限り、ユーザーが`--acknowledge-stop`を指定した場合だけ、固定された1要求の費用予約を許可する。通常の`--live`だけでは実行しない。これは停止後の診断に対する明示許可であり、対局再開や任意の要求の許可ではない。

| 許可する範囲 | 固定値 |
| --- | --- |
| 新たな要求ID | `response-diagnostic-v1` |
| 入力 | 停止した要求と同一 |
| モデル | `jev-1.13.0` |
| 要求の上限 | 1回 |
| 応答待ち上限 | 5,000ms |
| 費用区分 | 既存の予備試験枠$0.40の中 |
| 追加予約額の上限 | $0.002752512 |
| 予約込み累計の上限見込み | $0.013822368 |

元の41要求、停止した応答、棋譜、予算集計が確認済みの内容と一致することを確認する。明示許可の範囲と台帳の直前のハッシュを記録した後、同じ予算台帳へ診断1要求の予約・使用量を追記する。過去の停止記録、費用、台帳の連続性を保持し、停止フラグは変更しない。

異なる要求ID、別の入力、別の費用区分、待ち時間の変更は拒否する。全体の通常枠$4.50と予備試験枠$0.40を超える予約も拒否する。診断済みのIDは再送せず、保存応答を使うか、中断済みとして記録する。使用量が得られない場合は最大予約額を保持する。

## 実行方法

ZIPには本書、`response-diagnostic.cjs`、`response-diagnostic-manifest.json`の3ファイルだけが入っている。元のキットとこれまでの追加プログラム、設定ファイルを変更しない。

ZIPを`~/github/bao-la-kiswahili-game`直下に置く。最初に無課金確認を行う。

```bash
cd "$HOME/github/bao-la-kiswahili-game" &&
python3 -m zipfile -e bao-jev-response-diagnostic-v1.zip . &&
node tools/jev-comparison/response-diagnostic.cjs preflight
```

無課金確認が通り、上記の1要求だけを明示許可する場合は、APIキーを設定済みのターミナルで次を実行する。

```bash
cd "$HOME/github/bao-la-kiswahili-game" &&
node tools/jev-comparison/response-diagnostic.cjs run --live --acknowledge-stop
```

実行後、結果をまとめて共有する。

```bash
cd "$HOME/github/bao-la-kiswahili-game" &&
python3 -m zipfile -c bao-jev-response-results.zip tools/jev-comparison/results
```

キーが未設定の場合は送信前に停止する。以前と同じ非表示入力で設定する。キーはチャットへ貼り付けない。
